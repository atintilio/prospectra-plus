# Guia dos canais

Disponível para todos os usuários em Configurações → Como preparar seus canais.

## LinkedIn
Cada usuário entra em sua própria conta no navegador. No Prospectra: Campanhas → tarefa de LinkedIn → conferir contato e mensagem aprovada → abrir perfil → realizar ação → registrar conclusão. Modo assistido: não há envio automático ativado, compartilhamento de cookies ou necessidade de informar a senha ao Prospectra.

## WhatsApp
A versão atual tem uma sessão compartilhada pelo workspace, administrada pelo Owner. Não oferece número isolado por usuário. Configurações → Conectar conta WhatsApp → Iniciar gateway → Gerar QR Code. No celular comercial: WhatsApp → Configurações/menu → Dispositivos conectados → Conectar dispositivo → ler QR. Atualizar estado e confirmar Conectado. QR expirado: gerar outro. Não substituir um número em uso pela equipe.

Pareamento é uma ação humana no telefone. Somente mensagens aprovadas, com opt-in e conta elegível, seguem para envio. Falha deve ser reconciliada antes de tentar novamente.
